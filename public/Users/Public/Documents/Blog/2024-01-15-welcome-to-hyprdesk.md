# Welcome to HyprDesk

Welcome to my digital workspace! HyprDesk is a web-based desktop environment built from a fork of [daedalOS](https://github.com/DustinBrett/daedalOS).

## What is this?

This site is designed to feel like a real Linux desktop. You'll find:

- **A file system** you can browse
- **Apps** like a terminal, text editor, and more
- **A Windows-style taskbar** and desktop
- **Start menu** with all available applications

## Tokyo Night Theme

The entire interface uses the [Tokyo Night](https://github.com/folke/tokyonight.nvim) color palette — dark blues, cyan accents, and subtle purples. This matches the theme of my [Hyprdots](https://github.com/turquoise-hexagon/hyprdots) configuration.
