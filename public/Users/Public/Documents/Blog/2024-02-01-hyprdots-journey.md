# My Hyprdots Journey

I've spent countless hours crafting the perfect [Hyprland](https://hyprland.org/) desktop setup. Here's what I've learned.

## Why Hyprland?

Hyprland is a dynamic tiling Wayland compositor that offers:

- **Blazing fast** animations powered by your GPU
- **Full Wayland support** — no X11 baggage
- **Beautiful aesthetics** out of the box
- **Highly configurable** via a simple config file

## The Tokyo Night Setup

My config is built around the Tokyo Night color scheme:

- Background: `#1a1b26` (night sky)
- Accent: `#7aa2f7` (electric blue)
- Text: `#a9b1d6` (soft white)
- Highlight: `#bb9af7` (purple)

## Key Components

| Component | Choice | Why |
|---|---|---|
| Compositor | Hyprland | Best-in-class Wayland compositor |
| Bar | Waybar | Lightweight, highly customizable |
| Launcher | Rofi | Fast, themeable application launcher |
| Terminal | Kitty | GPU-accelerated, great font rendering |
| Editor | Neovim | Modal editing, Lua config |
